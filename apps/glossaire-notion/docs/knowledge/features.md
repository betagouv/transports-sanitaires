# Features of glossaire-notion

> What the app does, from its user's point of view. `tsp features glossaire`
> prints this table.

| Feature | What it does |
|---|---|
| Glossary popup | Shows the glossary kept in Notion, from the browser toolbar. |
| Search | Matches a query against terms and definitions, ignoring case and accents. |
| Local cache | Serves the glossary from a local copy, refetched from Notion when it goes stale. |
| Manual refresh | Refetches the glossary on demand. |
| No token | Reads the published Notion page: there is no secret to configure. |
