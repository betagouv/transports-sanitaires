# 04: Rendre la destination urgences cohérente (TS973-04)

**What to build:** un trajet vers un service d'urgences ne peut plus aboutir à
un résultat incohérent (domicile, EHPAD, ou contexte imposant une autre
destination) ; le prescripteur voit la structure de soins déduite dans le
récapitulatif.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Les sept contradictions de la famille AUD-ROUTE-URG-DEST ne finalisent
      plus un trajet incohérent
- [ ] Une arrivée cohérente aux urgences reste possible, sans déduire une
      hospitalisation ni un appel SAMU
- [ ] La famille de lieu déduite pour l'arrivée urgences est visible au
      récapitulatif
