# 13: Laisser vide le nombre itératif PMT pour un trajet unique (TS973-13)

**What to build:** une PMT prescrite pour un seul trajet n'affiche plus « 1 »
dans la rubrique des transports itératifs — elle reste vide, comme pour toute
prescription unique.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] PMT à un seul trajet : champ itératif vide

- [ ] Les nombres DAP et S3141 restent inchangés dans leurs propres rubriques
- [ ] Une ancienne valeur est vidée lors d'une nouvelle génération du document
