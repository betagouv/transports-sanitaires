# 10: Retirer le type d'hospitalisation obligatoire (TS973-10)

**What to build:** une entrée ou une sortie se finalise sans qu'on demande
complète/partielle/ambulatoire ; le texte médical n'ajoute plus cette
précision automatiquement.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] L'écran de type d'hospitalisation disparaît du parcours entrée/sortie
- [ ] Aucun sous-type n'est supposé par défaut
- [ ] Une ancienne valeur « Hospitalisation partielle » n'est plus ajoutée
      automatiquement au texte médical d'une simulation renouvelée dans la
      même visite
