# Structurer une règle de contribution

Ce skill ne porte aucune règle. Elles vivent toutes dans
[`docs/knowledge/contributing/`](../../../docs/knowledge/contributing/) :

| Fichier | Ce qu'il porte |
|---|---|
| `ecrire-une-regle.md` | le format d'une règle : squelette, identifiant, raison, exemples, garde, ce qu'il faut toucher en plus |
| `regles-de-code.md` | les `QUAL-*` |
| `regles-git.md` | les `GIT-*` |

## Marche à suivre

1. Lis `ecrire-une-regle.md` en entier, puis le recueil concerné.
2. Applique ce format à la règle à ajouter, modifier ou retirer.
3. Si une convention dont tu as besoin n'est écrite nulle part dans
   `docs/knowledge/contributing/`, ajoute-la là-bas. Jamais ici.
